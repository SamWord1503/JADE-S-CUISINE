# Jade's Cuisine

Premium catering booking app for Jade's Cuisine — Ibadan, Oyo State.

## Live App
https://jade-cuisine-catering.streamlit.app/

## Features
- Event booking form (name, phone, event type, date, guest count, venue, special requests)
- Auto-generated order reference IDs
- Instant price calculator with volume discounts (5% off 50+ guests, 10% off 100+ guests)
- WhatsApp order notifications via Twilio
- Orders stored in Supabase

## Tech Stack
Python, Streamlit, Supabase, Twilio
